Watch a model mark the statute

A model reads each provision and marks spans: exact phrases that carry a tax rule, such as the years, the number and who it applies to. Each span is checked against the statute, then the spans are turned into a value for each tax year and compared with the Department of Revenue's and PolicyEngine's.

Progress and checks

Checks on the spans from each run
RunSpans markedExact quotesUnreadableComplete

Exact quotes: spans that appear word for word in the statute. Any other span is dropped. Unreadable: spans marked as tax years, a percentage or a dollar amount that could not be read as one, so they are left out of the values below. Complete: provisions whose spans include every kind the data dictionary requires for that type of provision.

Point at a span to see what it was read as. A dashed outline means its dates or number could not be read. When a run ends, each provision is checked against the data dictionary: "Missing" names a kind of span that type of provision must have.
