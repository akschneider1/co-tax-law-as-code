Watch a model mark the statute

A model reads each provision and marks the words that carry a tax rule: the years, the number, who it applies to. Every mark is checked against the statute's own words, then turned into a value for each tax year and set beside the Department of Revenue's figure and PolicyEngine's. Press Run to see it happen.

What the model's marks say, year by year

Each value in the first column is built only from the spans this run marked: the tax years, the number and, for 2027, the bracket thresholds. Beside it are the value this project uses, which is the Department of Revenue's where it publishes one, and the value in PolicyEngine's Colorado model.

A difference is not always the model's mistake. The statute text here is an unofficial copy that is known to be out of date, so a model that reads it faithfully will disagree with the Department for some years.
